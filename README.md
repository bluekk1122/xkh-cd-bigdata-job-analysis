> 作者：XXX · 专科大数据技术专业 · 2027 届 · 地域聚焦成都（川渝）
> 项目定位：面向"高职大数据专科生如何在成都求职"的真实业务问题，完成**采集 → 清洗 → EDA → 可视化 → 结论**全流程分析。

## 一句话简介
用 373 条成都大数据岗位公开数据 + 高职可达性分层模型（L1/L2/L3），量化出**专科生 63.8% 的可投岗位面**，并定位到"数据开发/ETL"这一主攻方向，输出可指导投递决策的结论与看板。

## 核心结论
| 结论 | 数据 |
|---|---|
| 薪资看中位不看均值 | 中位 **18,000** vs 均值 22,097（右偏） |
| 学历有溢价但非天花板 | 本科比大专 +29.6%；"学历不限"中位 25,000 反超本科 |
| 真实可投面 = **63.8%** | L1+L2 = 238 / 373；专升本可解锁 216 个（57.9%） |
| 主攻方向 = 数据开发/ETL | 132 个岗（35%），且专科可达性最高 |

## 数据来源与合规
