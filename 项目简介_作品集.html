DATA ANALYSIS PROJECT · 简历 / 作品集项目介绍

大数据岗位招聘信息数据分析

大数据技术专业 · 专科 · 2027 届 · 有专升本计划 ｜ 地域聚焦：成都（川渝核心）
数据性质：政府及官方机构公开发布的岗位与人才需求信息，可溯源

一、项目背景与业务目标

背景

成渝地区双城经济圈将大数据相关产业列为核心增长极——四川把人工智能列为"一号创新工程"并建设行业高质量数据集与语料库，重庆将软件和信息服务业列为新增万亿级集群。《成都市人才需求清单》一次性集中推出 5610 个优质岗位，其中硕士及以上仅约 800 个，本科及以下可投岗位超 4800 个。但对高职专科生而言，面对海量且口径不一的招聘信息，往往陷入"看不懂、投不准"的困境：不清楚哪些岗位真实可达、需要补哪些技能、薪资与技能如何对应。

业务目标

回答一个具体的求职业务问题——"作为成都的高职大数据专科生，我能投什么岗位、该补什么技能"，而非单纯采集与堆砌数据。

通过采集成都官方公开发布的紧缺人才目录、产业规划与岗位信息，构建一份可溯源、可增量维护的结构化数据集，量化高职（含专升本路径）可达岗位与技能缺口，输出可直接指导投递决策的清单与看板。

  • 构建可溯源、可增量维护的成都数据类岗位结构化数据集（MVP 200–300 条官方高质量记录，中长期扩展至 ≥800 条有效记录）；
  • 量化高职可达岗位的占比、薪资与技能结构；
  • 输出《可投岗位清单》《补技能清单》两张求职决策表；
  • 沉淀一个可运行的分析项目（EDA + 可视化 + 后端 API），直接写入简历。

二、项目整体流程架构

① 数据采集→ ② 数据清洗→ ③ EDA 探索分析→ ④ 可视化→ ⑤ 结论输出
  • ① 数据采集：按"政策规划（L0）→ 紧缺目录（L1）→ 官方渠道真实岗位（L2）"三层结构采集，逐条保留 source_url 与 snapshot_date（采集快照日期），保证可溯源、可趋势化。
  • ② 数据清洗：字段归一（岗位名 / 技能标签映射表）、薪资口径标准化为"月薪中位数 / 元"（保留 salary_raw 原文）、去重（源 + 哈希主键）、高职可达性打标（L1 / L2 / L3 ＋ unlock_by 解锁路径）。
  • ③ EDA 探索分析：学历 / 经验要求分布、薪资分布、技能词频与薪资关联、政策赛道 ↔ 岗位映射、岗位地域分布等。
  • ④ 可视化：岗位缺口地图（城市 × 岗位族 × 紧缺度）、技能-薪资关联图、高职可达岗位看板。
  • ⑤ 结论输出：《可投岗位清单》《补技能清单》两张决策表 ＋ 作品集可运行项目（含后端 API 服务）。

每一层均强制带 snapshot_date 与 source_url，保证全链路可溯源、可趋势化。

三、数据源说明

级别数据源特点取数策略
L0 政策规划四川 / 成都"十五五"纲要、产业体系静态页、最稳定全采，定产业赛道
L1 紧缺目录成都市人才需求清单、省级紧缺职业目录、人社部新职业价值密度最高全采，定岗位族
L2 官方岗位人社局 / 人事考试网 / 市属国企 / 事业单位公开招聘公告零散、需辅助定点采，补真实在招岗位
公共开放数据四川 / 成都公共数据开放平台（无条件开放数据集）作品项目练手用挑"无条件开放"数据集做分析项目
❌ 不碰商业招聘平台自动化、含个人信息数据、有条件开放需协议数据法律风险 / 失真明确排除

选择依据：官方 / 公开源零法律风险、结构稳定、可溯源；商业平台用户协议禁止批量抓取、反爬强、存在"幽灵岗位"失真，故不做自动化。

四、项目预期分析问题（5 个业务问题）

  1. 可达性：成都数据类岗位对学历与经验的要求分布如何？高职专科生（含专升本路径）实际可达岗位占比多少？
  2. 岗位族差异：数据开发 / 数据分析 / 数据标注 / BI / 数据运维 / ETL 各岗位族的薪资区间与核心技能要求有何差异？
  3. 技能优先级：哪些技能出现频次最高、且与薪资正相关？应优先补齐哪几项（按"频次 × 薪资增益 × 学习成本"排序）？
  4. 政策-需求匹配：政策规划的产业赛道（人工智能 / 软件信息服务 / 工业数据）与实际岗位需求是否匹配？哪些方向对高职生更友好？
  5. 地域分布：岗位在成都各区县的分布与紧缺度如何？是否值得向都市圈（德眉资）拓展求职？

五、项目局限性说明（如实披露，面试加分项）

  • 来源偏差：以官方 / 公开目录为主，未覆盖商业招聘平台全量，样本偏向"规划导向"岗位，结论不可外推为整体市场供需。
  • 时效滞后：官方目录多为年度报告 / 季度发布，数据非实时；已用 snapshot_date 快照机制缓解趋势缺失，但仍存在时滞。
  • 口径损失：薪资多为区间或"面议 / 年薪 / 带提成"混合口径，标准化为月薪中位数存在精度损失，已保留 salary_raw 原文溯源。
  • 主观判定：L1 / L2 / L3 可达性分层基于个人画像（专科 ＋ 专升本计划）做主观标注，unlock_by 解锁路径为建议性而非雇佣方承诺。
  • 样本规模：官方源有效岗位有限（MVP 200–300 条），统计置信区间较宽，细分维度（如单区县 × 单一岗位族）样本可能不足。
  • 合规边界：数据仅用于个人学习研究与求职，不对外分发原始明细，成果仅发布聚合统计结论；未获取任何求职者个人信息。

一句话版（简历项目经历）

成都大数据岗位情报分析（个人项目）：采集成都市人才需求清单、紧缺职业目录等官方公开数据，构建可溯源岗位数据集（MVP 200+ 条，目标 ≥800 条），通过薪资标准化与高职可达性分层（L1/L2/L3），量化专科生在成都的可投岗位与技能缺口，输出《可投岗位清单》《补技能清单》及可视化看板，支撑求职决策。

段落版（作品集网站 / 项目详述）

本项目面向"高职大数据专科生如何在成都求职"这一真实业务问题，采集政府及官方机构公开发布的大数据岗位与人才需求信息，构建可溯源、可增量维护的结构化数据集。项目完整覆盖"数据采集 → 数据清洗 → EDA 探索分析 → 可视化 → 结论输出"标准技术链路，并对每条记录强制保留来源 URL 与采集快照以保证严谨性。在清洗阶段引入高职可达性分层（L1 可达 / L2 跳一跳 / L3 暂不可达）与专升本解锁路径标注，最终量化岗位学历 / 经验要求、薪资分布与技能结构，输出可指导投递决策的《可投岗位清单》《补技能清单》及可视化看板。
