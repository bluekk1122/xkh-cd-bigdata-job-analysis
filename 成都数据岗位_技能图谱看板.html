可写进简历 / 面试讲的结论

  • 大数据岗的技能关键词高度集中在「数据工程」而非「算法」。出现最多的是数据治理（19 次）、数据库（17 次）、数据仓库/数仓（9 次）、ETL（5 次）——这说明该岗位族的核心是把数据管起来、跑通，不是训模型。
  • Python 与 Java 是通用底座。两者出现次数不算最高（各 4、7 次），但都是基准线以上的薪资，属于"不会就进不去、会了不加分"的必备项。
  • 数据中台是薪资最高但样本最少的方向（5 次，中位 45000）。样本太小不宜当成规律，但它提示：平台化/中台建设类岗位溢价明显，可作为长期目标而非入门方向。
  • 数据标注是明确的低薪陷阱。3 次出现，中位 6000 元，比整体低 8500 元。作为过渡可以，不要当职业方向。
  • 学历门槛比想象中硬。大数据岗 94 条里大专只有 4 个（4.3%），本科 78 个；经验要求集中在 3-10 年。专升本 + 项目经验，是进入这个岗位族几乎绕不开的两步。
